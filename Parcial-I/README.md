## Descripción del programa
Programa en Java diseñado para modelar los procesos fundamentales de un cajero bancario interactivo.
Incluye autenticación de usuario con PIN limitado a tres intentos, consulta de balance disponible y abonos.
Permite realizar retiros comunes y con cobro adicional a través de métodos sobrecargados, finalizando con un informe general de la sesión.

## Indicación de cómo ejecutar la clase principal
Corra la clase principal `CajeroAutomatico.java` por medio de su IDE o consola de comandos, y digite el código PIN `2026` en el momento que la interfaz lo solicite.

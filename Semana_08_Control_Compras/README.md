# Sistema de Control de Compras Domésticas

**Estudiante:** Jussely Saraí Mutas Chitic  
**Carné:** (9941-25-28221)

El presente programa es una aplicación desarrollada en Java para la gestión, registro y evaluación de gastos en compras del hogar. Su propósito principal es aplicar conceptos de la Programación Orientada a Objetos (POO), estructuras de control y la selección eficiente de colecciones en Java (`ArrayList`, `HashSet` y `HashMap`).

El sistema permite registrar productos con validación estricta de datos, procesar subtotales y acumulados por categoría, determinar los artículos con mayor y menor impacto económico, y realizar consultas interactivas por categoría.

## Cómo Ejecutar el Proyecto

### Opción 1: Desde IntelliJ IDEA (Recomendado)

1. Abre el proyecto en **IntelliJ IDEA**.
2. Navega a la ruta `src/MainControlCompras.java`.
3. Haz clic en el botón **Play** (`▶`) en la esquina superior derecha o al lado del método `main`.
4. Interactúa con la consola integrada en la pestaña **Run**.

# Cálculo de Áreas de Figuras Geométricas

## Breve descripción
Aplicación de consola desarrollada en Java que aplica conceptos de Programación Orientada a Objetos (POO) como abstracción, encapsulamiento, herencia, sobrescritura y polimorfismo para calcular y mostrar el área de diferentes figuras geométricas mediante un arreglo de tipo base.

## Figuras implementadas
- Círculo
- Rectángulo
- Triángulo

## Instrucciones para ejecutar el programa
1. Abre una terminal o consola de comandos.
2. Navega hasta el directorio raíz del proyecto (donde se encuentra la carpeta `src`).
3. Compila los archivos Java ubicados en la carpeta src:
   ```bash
   javac src/*.java

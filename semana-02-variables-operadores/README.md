# Tarea 1 - Variables y Operadores: Calculadora de Edad

## Descripción

Este programa solicita el nombre, carné, año de nacimiento y año actual del estudiante. Posteriormente calcula la edad aproximada, la edad aproximada en meses y determina si la persona es mayor de edad mediante una variable de tipo boolean.

## Datos solicitados

- Nombre completo
- Carné
- Año de nacimiento
- Año actual

## Cálculos realizados

- Edad aproximada
- Edad aproximada en meses
- Verificación de mayoría de edad

## Instrucciones para ejecutar el programa

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase `CalculadoraEdad.java`.
3. Ingresar los datos solicitados.
4. Observar los resultados mostrados en la consola.

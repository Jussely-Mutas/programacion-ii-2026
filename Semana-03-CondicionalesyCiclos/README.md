## 💻 Funcionalidades del Menú

El programa despliega un menú interactivo con las siguientes opciones:

1. **Generar una secuencia:** Solicita inicio, fin e incremento para iterar una secuencia numérica utilizando un bucle `for` con validaciones previas.
2. **Realizar un conteo regresivo:** Valida un rango de entrada (entre 10 y 50) e imprime una cuenta regresiva hasta 0 finalizando con un mensaje de despegue.
3. **Analizar números:** Procesa múltiples entradas numéricas, ignora los múltiplos de 5 mediante `continue`, clasifica positivos/negativos y calcula la suma total hasta ingresar el número `0`.
4. **Dibujar una pirámide:** Genera una pirámide alineada e impresa con asteriscos (`*`) con una altura entre 3 y 10 niveles usando ciclos anidados.
5. **Validar palabra secreta:** Solicita la contraseña esperada (`Guatemala`) y repite la petición mediante un ciclo `do-while` hasta que se ingrese correctamente (sin importar mayúsculas/minúsculas).
6. **Salir:** Finaliza la ejecución del programa de forma limpia.

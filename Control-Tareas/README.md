# Actividad: Control de Tareas 

## Descripción del Problema
Este proyecto consiste en el diseño lógico de una API REST y la implementación de un programa de consola en Java orientado a la gestión y control de tareas personales. Permite categorizar tareas por su prioridad y dar seguimiento a su estado de finalización.

## Tecnologías Utilizadas
* Java 17 (o superior)
* Apache Maven
* JSON (Diseño de formato)
* REST / HTTP (Diseño de API)

## Datos del Proyecto Maven
* **groupId:** com.estudiante
* **artifactId:** control-tareas
* **version:** 1.0-SNAPSHOT

## Explicación de Conceptos Maven
* **groupId:** Identificador único de la organización o paquete del proyecto.
* **artifactId:** Nombre del proyecto o módulo generado.
* **version:** Identificador del estado o versión del proyecto en desarrollo.

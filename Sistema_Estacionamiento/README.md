# Examen Parcial II — Sistema de Gestión de Estacionamiento y Base de Datos

Este repositorio contiene la solución completa para el Examen Parcial II, el cual se divide en un sistema en **Java (Programación Orientada a Objetos y Colecciones)** y un script estructurado en **PostgreSQL**.

---

## 📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo e integración de un sistema de gestión para un estacionamiento:

1. **Aplicación en Java (POO y Colecciones):** Sistema de consola que administra el ingreso y cobro de vehículos (`Automovil` y `Motocicleta`), aplicando abstracción, herencia, encapsulamiento, polimorfismo, manejo de excepciones (`try-catch-finally`) y colecciones (`ArrayList`, `HashSet` y `HashMap`).
2. **Base de Datos Relacional (PostgreSQL):** Script SQL que define la tabla `vehiculo` con restricciones (`PRIMARY KEY`, `UNIQUE`, `CHECK`), inserción de datos de prueba, consultas (`SELECT`), actualizaciones (`UPDATE`), eliminación física (`DELETE`) y pruebas de error controladas.
